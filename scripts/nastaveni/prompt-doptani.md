Nevyhledávej znovu — použij to, co už jsi našel. Vrať teď POUZE platné JSON pole přesně podle zadání výše, s jedním záznamem pro každý z bodů: {{SEZNAM_ID}}. Začni znakem [ a skonči znakem ]. Žádný text před ním ani za ním, žádné shrnutí, žádné markdown bloky. Rovné uvozovky uvnitř textu buď escapuj (\"), nebo piš české „takto“.
